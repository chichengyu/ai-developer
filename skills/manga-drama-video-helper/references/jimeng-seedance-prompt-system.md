# 即梦 Seedance 2.0 提示词体系

来源：

- 即梦 AI 技能中心：https://jimeng.jianying.com/ai-tool/home?activeTab=skill
- Seedance 2.0 官方使用手册
- 即梦技能提示词社区提炼

用于 Phase 1 的 `motion_text`、Phase 3 的图生视频，以及用户明确选择即梦在线平台时的 `05_jimeng_prompt_pack.md`。

## 多模态引用语法

只使用官方引用命名：

```text
@图片1 作为人物形象
@图片2 作为场景背景
@视频1 参考人物运动节奏
@音频1 作为配乐
```

- 图片最多 9 张，视频最多 3 个，音频最多 3 个。
- 禁止混用 `@img`、`@video`、`@audio`、`图1` 等非官方写法。
- 每个引用必须说明用途，不能只写 `@图片1`。
- 写实真人清晰脸部素材不能作为参考图。

## 提示词公式

每个 `motion_text` 必须包含：

```text
[主体/人物] + [场景/环境] + [动作/运动] + [运镜语言] + [分时段] + [转场/特效] + [音频/音效] + [风格/氛围]
```

示例：

```text
林暮在山门石阶上侧身疾走，
动作：右脚向前迈出，右手将长剑从下向左上斜斩，剑锋划出银色弧光，
物理：重心从后脚移到前脚，衣摆和头发随动作受重力摆动，脚步不滑动，武器始终在手，
运镜：镜头从中景推近到过肩近景，推近速度先慢后快，
时间：0-2 秒蓄力，2-4 秒斩击，4-5 秒收势，
特效：斩击命中瞬间出现一道白色气浪，不出现乱码文字，
音频：剑鸣声在第 2.5 秒进入，衣袂声持续，环境风声作为底噪，
氛围：傍晚冷青调，金色逆光，电影级仙侠打斗，非说话镜头嘴巴闭合。
```

## 分时段

4-15 秒为一个镜头。超过 6 秒必须按时间段拆写：

| 时间段 | 作用 | 示例 |
| --- | --- | --- |
| 0-3s | 建立动作起点与镜头关系 | 人物进入画面，镜头跟随 |
| 3-6s | 主动作与碰撞点 | 斩击命中，气浪爆发 |
| 6-10s | 反应与收势 | 人物侧身落地，衣发余动 |
| 10-15s | 镜头离开或转场 | 镜头拉远，下个镜头匹配 |

一个镜头只保留一个主动作、一个主运镜、一个主音效。不要在 4 秒内塞多个场景。

## 运镜语言

写具体词，不要写“镜头动一下”：

- 推 / 拉：`push-in` / `pull-back`
- 摇：`pan-L` / `pan-R`
- 跟随：`follow` / `mechanical-arm follow`
- 环绕：`orbit 20-30 degrees`
- 一镜到底：`one-take, continuous camera`
- 希区柯克变焦：`dolly-zoom`
- 低角度仰拍 / 俯拍：`low-angle up-shot` / `high-angle down-shot`
- 主观视角：`POV`
- 快速摇镜：`whip-pan`
- 机械臂跟随：`crane/mechanical-arm follow`

不要写“镜头先固定再环绕”的冲突描述。

## 即梦在线提示词包

仅当用户明确选择即梦在线平台时生成 `05_jimeng_prompt_pack.md`。每个镜头写：

```text
## SH1.1

@图片1 作为首帧，@图片2 作为人物形象，@图片3 作为场景背景，
@视频1 参考人物运动节奏，@视频2 参考完整招式，@视频3 参考环绕运镜，
@音频1 作为配乐，@音频2 作为剑鸣音效，
林暮在山门石阶上侧身疾走，0-2 秒蓄力，2-4 秒斜斩，
镜头从中景推近到过肩近景，第 2.5 秒剑鸣，
傍晚冷青调，金色逆光，写实动漫，电影级仙侠打斗。
```

## 一致性策略

1. 人物一致性优先用图：首帧、人物形象、服装、构图尽量引用参考图。
2. 每个镜头固定 seed，并复用 Phase 2 生成的 canonical refs。
3. 15 秒以上的动作拆成首尾帧链：上一段尾帧作为下一段首帧。
4. 生成后必须检查脸型、服装、武器、场景结构是否漂移；发现漂移就换回 refs 重跑，不能只改文字。
