# Seedream 5.0 Pro 提示词体系

来源：

- 火山方舟模型页：https://ark.volcengine.com/region:cn-beijing/model/detail?name=doubao-seedream-5-0-pro
- Seedream 5.0 Pro 交互编辑指南
- Seedream 系列模型 API 文档

用于 Phase 1 的 `image_prompt`、Phase 2 的人物/场景/参考图生成，以及任何需要精准位置控制的图片编辑。

## 模型与限制

- 首选 Model ID：`doubao-seedream-5-0-pro-260628`
- 支持文生图、单图/多图生图、交互编辑；最多 10 张参考图。
- 输出分辨率档位：`1K`、`1.5K`、`2K`。`1.5K` 与 `1K` 价格相同，质量更好。
- 输出格式：`png`、`jpeg`。
- 原生多语言文字生成，但分镜中未指定的区域不要出现文字。
- 文本提示词建议不超过 300 个汉字或 600 个英文单词；过长会分散模型注意力。
- `Seedream 5.0 pro` 不支持组图输出和联网搜索；组图需求改用 lite 或逐张生成。

## 七层提示词公式

每个 `image_prompt` 按以下顺序组织：

```text
[格式/用途] + [主体/人物] + [构图/空间] + [光影] + [画面内文字] + [风格/质感] + [锁定项]
```

示例：

```text
9:16 漫剧竖屏关键帧，电影剧照，
主体：写实动漫风格的剑修「林暮」，黑发高马尾，青灰长袍，右手握黑鞘长剑，
构图：低角度中景，人物在画面左三分之一，右侧留出剑气轨迹，山门石阶作背景，
光影：傍晚逆光，人物边缘暖金色轮廓光，背景冷青，面部有主光，
画面内文字：无文字，不生成字幕、水印或乱码，
风格：真实逼真、轮廓分明，皮肤有自然纹理，电影级调色，
锁定：保持参考图中林暮的脸型、发型、服装、剑的形制、山门结构和机位不变。
```

## 参考图规则

1. 按内容指代参考图，不写“第一张图”；例如“参考图中的林暮作为人物形象”。
2. 每张参考图说明用途：人物身份、面部结构、表情范围、招牌动作、场景结构、材质、画风、构图。
3. 锁定项必须点名：脸型、发型、服装结构、武器、背景、机位、光线。
4. 多人镜头给每个主要角色一张 canonical ref，再加一张构图参考。
5. 角色参考优先用干净、无遮挡、无夸张滤镜的正脸和 3/4 侧面。

## 交互编辑与坐标

支持 `<point>` 和 `<bbox>`，坐标范围 `0-999`，左上角 `0,0`，右下角 `999,999`。

```text
把图1 <point>520 460</point> 位置换成王冠
把图1 <bbox>120 180 640 760</bbox> 区域换成花园
将图1 <bbox>179 283 796 986</bbox> 的主体放到图2 <bbox>118 331 933 871</bbox> 位置
把图1 <bbox>120 180 640 760</bbox> 区域内左侧人物换成机器人
把图1 <bbox>120 180 640 760</bbox> 区域换成花园，图1 <bbox>700 120 920 360</bbox> 区域保持不变
```

多主体区域中必须写清编辑目标，例如“区域内戴帽子的猫”“画面左侧的人”，避免模型选错对象。

## API 参数要点

```json
{
  "model": "doubao-seedream-5-0-pro-260628",
  "prompt": "9:16 漫剧关键帧...",
  "image": "data:image/png;base64,...",
  "size": "2K",
  "response_format": "b64_json",
  "output_format": "png",
  "watermark": false,
  "optimize_prompt_options": {
    "mode": "standard"
  }
}
```

`optimize_prompt_options.mode` 可选 `standard` 或 `fast`；`fast` 更快但质量略降。
