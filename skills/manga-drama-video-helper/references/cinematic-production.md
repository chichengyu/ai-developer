# 电影级运镜、打斗与嘴型同步

用于 Phase 3，也用于 Phase 1 写分镜和 Phase 2 生成运镜素材。目标是“丝滑、有电影大片感、动作真实可信”。

## 电影级运镜

每个镜头都要有完整的镜头意图，禁止只写“镜头动一下”。

1. 写清楚起点和终点：
   - 起点机位、景别、主体位置
   - 终点机位、景别、主体位置
   - 镜头移动方向、速度、是否带缓动
2. 使用具体运镜语言：
   - `push-in` 慢推建立压迫感
   - `pull-back` 拉开揭示宏大空间
   - `pan-L/pan-R` 跟随人物或揭示环境
   - `tilt-up/tilt-down` 揭示高度或力量
   - `orbit 20-30 degrees` 环绕展示人物与环境关系
   - `dolly-zoom` 用于情绪爆点
   - `crane/mechanical-arm follow` 制造高低落差
   - `whip-pan` 用于战斗转场或突然打断
3. 运动速度必须符合物理感：开始慢、中间快、结束缓；不能匀速僵硬，不能乱抖。
4. 镜头移动必须与主体动作同步，不能人物已经出画镜头才跟上。
5. 长镜头超过 6 秒必须拆段，并锁定上一段尾帧与下一段首帧，保证运镜连续。

## 宏大场景

场景提示词必须包含空间规模、纵深、层次和参照物：

```text
wide shot，山门横跨画面，石阶向远处延伸，人物在石阶下方，
前景有飘雪，中景是山门与火把，背景是层叠山峦和云海，
低角度仰拍，让山门显得高耸压迫，镜头缓慢拉起，
画面保留大量天空负空间，突出天地之大人物之小。
```

每个宏大场景至少满足：

- 有明确的远、中、近三层空间。
- 有参照物表达尺度，例如城门、山崖、云海、千军万马。
- 人物与场景保持正确比例，不能人物占据整个画面却没有环境信息。
- 灯光有层次，主光、轮廓光、背景氛围光分离。

## 打斗分镜

打斗动作必须按真实电影动作片拆解，不能用“两人打起来”这种抽象提示词。

每个打斗镜头必须包含：

1. 预备：重心下沉、握紧武器、呼吸停顿。
2. 发力：腿部/腰部发力顺序明确，武器沿合理弧线运动。
3. 接触/冲击：命中瞬间有冲击帧、镜头震动或气浪，但不能破坏动作连续。
4. 反应：被击中方有受力方向和惯性位移，不原地瞬移。
5. 收势：重心复位、衣发余动、镜头跟随到静止。

示例：

```text
0-1 秒：林暮重心下沉，右手握剑，剑尖垂地，呼吸停顿；
1-2 秒：左脚蹬地，腰胯发力，剑从右下向左上斜斩；
2-3 秒：剑锋击中对方兵器，碰撞点出现白色气浪，镜头轻微后坐；
3-4 秒：对方身体后仰，脚向后滑半步，手臂被震开；
4-5 秒：林暮顺势转身收势，衣摆和头发继续摆动，剑停在身侧。
```

硬性禁止：

- 人物悬空、脚步滑动、手脚穿模、四肢分离。
- 动作没有重量和惯性，直接从一个 pose 跳到另一个 pose。
- 打斗双方不同步，一方已经命中另一方还没反应。
- 慢动作滥用；只在关键冲击帧使用短暂慢动作。

## 嘴型与对话音频同步

说话镜头必须由音频驱动嘴型：

1. 每个说话镜头绑定对应的 `audio/voice/<line_id>.mp3`。
2. 嘴型必须匹配音素、重音和停顿；张开时间不能比音频早或晚超过 100ms。
3. 非说话镜头嘴巴闭合，不能一直张着。
4. 情绪同步：喊叫、低语、喘息都要有对应表情和呼吸节拍，不能只有嘴动。
5. 数字人或写实动漫角色优先使用音频驱动 lip sync 工具；没有工具时不能声称嘴型已经同步。

当前模型/API（例如 MiniMax-H3）支持 `audio_url` + 人物参考图/视频时，直接由它生成说话镜头：音频输入用 WAV/MP3，单段 2-15 秒且不超过 15MB，必须配合图片或视频输入，嘴型会由音频驱动，不需要把台词塞进 prompt 或生成黑屏视频。如果必须保留前期 TTS/录音的精确音频，先验证 H3 返回视频是否保留该音频；不能保留时，以 H3 原生生成音频为成片配音，或用云口型 API 做精确音频对齐。

## 表情与情绪真实

人物情绪不能只靠一句“生气”或“难过”描述，必须拆成可执行的表情层：

1. 眼睛：瞳孔大小、视线方向、眨眼频率、眼神是躲闪还是直视。
2. 眉毛：上挑、下压、皱起、单侧挑动。
3. 嘴角：抿紧、微颤、上翘、下撇。
4. 呼吸：胸口起伏、鼻息、停顿。
5. 身体：肩膀耸起或下沉、手指收紧、重心前倾或后退。
6. 情绪灯光：愤怒用硬光，悲伤用冷调低照度，希望用暖光，情绪变化时灯光跟着变化。

示例：

```text
林暮看到遗物时不是直接哭，而是先屏住呼吸，
视线从玉佩移到师兄的空座位，嘴唇抿紧，喉结滚动，
手指慢慢收进袖口，肩膀下沉，眼眶微红但不落泪，
灯光从冷青转为一点暖色，人物没有大幅表情，却让观众感到隐忍。
```

硬性禁止：

- 同一角色在情绪切换时表情直接跳变，没有过渡。
- 喜怒哀乐只用一种表情标签，没有微表情和身体反应。
- 人物表情与当前台词、语气、BGM 情绪脱节。

## 中英双语字幕

1. 中文一行、英文一行，中文优先显示在上。
2. 中文字幕每行不超过 18 个汉字；英文字幕每行不超过 36 个字符。
3. 一个 cue 最多 4 行：中文 2 行 + 英文 2 行。
4. 字幕时间轴与 `audio/voice/` 对齐，不能提前或滞后超过 200ms。
5. 旁白用 `[旁白]`，角色用 `[角色名]`；英文标签保持同一格式。
6. 字幕不能遮挡人物脸部和关键动作，底部留安全边距。

## 验收清单

- [ ] 每个镜头有起点/终点运镜和缓动。
- [ ] 镜头运动与人物动作同步。
- [ ] 宏大场景有远中近三层和尺度参照。
- [ ] 打斗镜头包含预备、发力、接触、反应、收势。
- [ ] 动作无悬浮、无脚步滑动、无穿手。
- [ ] 说话镜头嘴型与音频逐句对齐。
- [ ] 非说话镜头嘴巴闭合。
- [ ] 关键镜头有微表情、眼神、呼吸和身体张力变化。
- [ ] 情绪切换有过渡，不与台词和 BGM 脱节。
- [ ] 字幕为中英双语，中文 18 字/行、英文 36 字符/行，时间轴对齐。
- [ ] 音效进入时间与冲击帧一致。
- [ ] 视频没有卡顿、跳帧、生硬切镜。
