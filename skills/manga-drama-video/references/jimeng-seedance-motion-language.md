# 即梦 Seedance 2.0 多模态提示词体系（整合为本机 motion prompt 规范）

来源：

- 即梦 AI 技能中心：https://jimeng.jianying.com/ai-tool/home?activeTab=skill
- Seedance 2.0 官方使用手册与社区 skill 提炼，核心交互语法为 `@图片1 @视频1 @音频1`

本文件用于 Step 3/5/6。默认把 Seedance 的“多模态参考 + 运动语言”翻译成当前模型/API 的 `motion_text` 和参考包；只有用户明确选择本地模式时，才按 `references/video-motion-generation.md` 翻译成本地 Wan / HunyuanVideo / LTX-Video 的模板。只有用户明确选择即梦在线工具时，才在 `output_root/scripts/<slug>/jimeng_prompt_pack.md` 生成严格 `@` 语法包，不做强制复制回流。

## 多模态输入

Seedance 2.0 最多接收 12 个参考文件：9 图 + 3 视频 + 3 音频，单次生成 4-15 秒，约 480P 到 720P 竖屏。参考图不能是写实真人清晰脸部素材。

本 skill 的 `reference_bundle.json` 同样是 9 图 + 3 视频 + 3 音频，但每个槽位都有固定语义，比即梦更可追溯：

| 类别 | 槽位 | 即梦对应写法 |
| --- | --- | --- |
| 图片 | `character_front` / `character_three_quarter` / `character_side` / `character_expression` / `character_action` | `@图片1 作为人物形象，@图片2 作为表情参考` |
| 图片 | `scene_wide` / `scene_detail` | `@图片3 作为场景背景，@图片4 作为场景细节参考` |
| 图片 | `style_reference` / `composition_reference` | `@图片5 作为画风参考，@图片6 作为构图和机位参考` |
| 视频 | `motion_primary` | `@视频1 参考人物的运动节奏和惯性` |
| 视频 | `action_beat` | `@视频2 参考完整招式：预备、发力、击中、反应、收势` |
| 视频 | `camera_move` | `@视频3 参考镜头运动：推拉摇移、环绕、甩镜` |
| 音频 | `voice_timbre` / `emotion_line` | `@音频1 参考音色，@音频2 参考这句台词的语气` |
| 音频 | `ambience_sfx` | `@音频3 作为环境音和音效参考` |

## 提示词公式

每个 `motion_text` 必须包含：

```text
[主体/人物] + [场景/环境] + [动作/运动] + [运镜语言] + [分时段] + [转场/特效] + [音频/音效] + [风格/氛围]
```

### 通用 motion_text 模板

```text
白发剑修在山门前的石阶上侧身疾走，
动作：右脚向前迈出，右手将长剑从下向左上斜斩，剑锋划出银色弧光，
物理：重心从后脚移到前脚，衣摆和头发随动作受重力摆动，脚步不滑动，武器始终在手，
运镜：镜头从正面中景推近到过肩近景，推近速度先慢后快，
时间：0-2 秒蓄力，2-4 秒斩击，4-5 秒收势，
特效：斩击命中瞬间出现一道白色气浪，不出现乱码文字，
音频：剑鸣声在第 2.5 秒进入，衣袂声持续，环境风声作为底噪，
氛围：傍晚冷青调，金色逆光，电影级仙侠打斗，非说话镜头嘴巴闭合。
```

### 即梦在线 prompt 模板（仅用户明确选择时）

```text
@图片1 作为首帧，@图片2 作为人物形象，@图片3 作为场景背景，
@视频1 参考人物运动节奏，@视频2 参考完整招式，@视频3 参考环绕运镜，
@音频1 作为配乐，@音频2 作为剑鸣音效，
白发剑修在山门前侧身疾走，0-2 秒蓄力，2-4 秒斜斩，
镜头从中景推近到过肩近景，第 2.5 秒剑鸣，
傍晚冷青调，金色逆光，写实动漫，电影级仙侠打斗。
```

## 分时段

10 秒以上的长镜头必须按时间段拆分描述，本 skill 对超过 6 秒的镜头还会拆成首尾帧链：

| 时间段 | 作用 | 示例 |
| --- | --- | --- |
| 0-3s | 建立动作起点和镜头关系 | 人物进入画面，镜头跟随 |
| 3-6s | 主动作与碰撞点 | 斩击命中，气浪爆发 |
| 6-10s | 反应与收势 | 人物侧身落地，衣发余动 |
| 10-15s | 镜头离开或转场 | 镜头拉远，下个镜头匹配 |

即梦官方建议不要在同镜头既固定又环绕，也不要在 4 秒里塞太多场景。本机同样遵守：每个 4-15 秒镜头只保留一个主动作、一个主运镜、一个主音效。

## 运镜语言

写进 `motion_text` 的运镜词必须具体：

- 推 / 拉：`push-in` / `pull-back`
- 摇：`pan-L` / `pan-R`
- 跟随：`follow` / `mechanical-arm follow`
- 环绕：`orbit 20-30 degrees`
- 一镜到底：`one-take, continuous camera`
- 希区柯克变焦：`dolly-zoom`
- 低角度仰拍 / 俯拍：`low-angle up-shot` / `high-angle down-shot`
- 主观视角：`POV`
- 快速摇镜：`whip-pan`
- 机械臂跟随：`crane/mechanical-arm follow`

不要在 `motion_text` 里只写“镜头动一下”。Step 3 的 `camera_move` 和 `motion_text` 必须一致，Step 5 的视频扩散才可能原生生成运镜。

## 参考使用规则

1. **每个参考都要说明用途。** 只写 `@图片1` 而不写用途等于没有参考。
2. **引用必须点名内容。** “@图片1 中的白发剑修作为人物形象”比“参考第一张图”更稳定。
3. **音频是质量杠杆。** 配乐、音效、节奏卡点都应在 prompt 中给出进入时间，不要让模型随机决定。
4. **人物一致性优先用图。** 首帧、人物形象、服装、构图尽量用参考图，文字只负责动作和镜头。
5. **短时长不要塞太多场景。** 4-8 秒一个主场景，9-15 秒最多一个场景内连续动作。
6. **不依赖平台记忆做长镜头。** 本机用 `--start-image` / `--end-image` 首尾帧链，跨片段审计。

## 与本地引擎的映射

| Seedance 概念 | 本机实现 |
| --- | --- |
| `@图片N` | `--ref-bundle reference_bundle.json` 的图片槽位 |
| `@视频N` | `reference_bundle.json` 的 3 个视频槽位，首尾帧提取 |
| `@音频N` | `reference_bundle.json` 的 3 个音频槽位 + `06_voice/index.json` |
| 首帧 / 尾帧 | `--image 05_images/<shot>.png` + `--end-image` |
| 运镜复刻 | `motion_text` 写清运镜词，`camera_move` 字段同步 |
| 分时段 | `motion_text` 按 0-3s / 3-6s / 6-10s / 10-15s 写 |
| 节奏卡点 | `sfx` 字段记录音效进入时间，Step 7 时间轴对齐 |
| 人物一致性 | canonical refs + 固定 seed + continuity audit |

## 避坑清单

- 不写 `@图片` 却不说明用途。
- 不写“镜头先固定再环绕”的冲突描述。
- 不用写实真人清晰脸部素材做参考，本机生成角色也不得模仿真实人物。
- 不把 15 秒以上的镜头一次生成，本机拆段并锁首尾帧。
- 不把平台生成的视频当作本机产物；只有用户明确选择即梦在线工具时，`jimeng_prompt_pack.md` 才允许生成，且仍需通过一致性审计。
