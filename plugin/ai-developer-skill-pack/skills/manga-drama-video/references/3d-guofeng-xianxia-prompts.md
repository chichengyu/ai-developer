## 与现有 skill 的合并规则

1. **默认锁定 3D 国漫风格**：当用户选择 3D 国风动漫时，所有 `image_prompt` 必须带上“3D国风动漫 + 国漫玄幻风格 + CG电影渲染 + 次世代建模 + PBR真实材质 + 角色一致性 + 8K超高清”。
2. **保持真实逼真、轮廓分明**：在原文关键词后追加 `hyper-real skin texture, visible pores, clean sharp face edges, high contrast outline, no plastic skin, no flat anime shading`，避免生成塑料感和传统二次元平涂。
3. **角色一致性**：每个角色先生成参考图，锁定 seed，并逐字复用“同一人物设定，同一张脸……”这一段。
4. **数字真人 override**：若用户选择数字真人，将“3D国风动漫/CG电影渲染”替换为 `photorealistic digital human, ultra-detailed skin, no stylization, no anime outlines, cinematic natural lighting`，其余服装、场景、镜头与角色一致性规则保留。
5. **公式化组合**：按“人物设定 + 外貌特征 + 服装配饰 + 动作神态 + 场景环境 + 镜头类型 + 光影效果 + 材质表现 + 国风玄幻风格 + 角色一致性 + 电影级渲染 + 8K 超高清”的顺序组织 prompt，不要漏项。
6. **不要混建模语言**：同一项目只能选“3D 国风动漫”或“写实动漫”或“数字真人”之一，禁止单集内混用多种建模体系。
