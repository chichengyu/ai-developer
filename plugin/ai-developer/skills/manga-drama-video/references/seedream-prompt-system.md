# Seedream 5.0 Pro 图像提示词体系（整合为本机图像 prompt 规范）

来源：

- 火山方舟模型页：https://ark.volcengine.com/region:cn-beijing/model/detail?name=doubao-seedream-5-0-pro
- 火山引擎提示词指南：https://docs.volcengine.com/docs/82379/1829186?lang=zh
- Runware API prompting guide（2026-07）：https://runware.ai/docs/models/bytedance-seedream-5-0-pro/guides/prompting

本文件用于 Step 2/3/4/5。目标不是让用户跳转到即梦或豆包网页生成图片再回流，而是把 Seedream 的“生产简报式”提示词结构吸收到本机 imagegen / ComfyUI / SD WebUI 的 `image_prompt` 里。只有用户明确指定外部平台时，才额外生成该平台可用的提示词包。

## 核心能力

| 能力 | 说明 | 本机对应用法 |
| --- | --- | --- |
| 文生图 | 用自然语言生产简报生成图片 | `generate_images.py --prompt "<分层 prompt>"` |
| 图生图 / 参考编辑 | 传参考图后只改指定部分，未提及内容保持参考图原样 | 用 canonical refs + IPAdapter/ControlNet/inpaint |
| 多图融合 | 最多约 10 张参考图，把多个角色、产品、场景融合到一张画面 | `reference_bundle.json` 的 9 图槽位逐张绑定语义 |
| 交互式编辑 | 坐标、框选、草图、材质/颜色指令，只改局部 | ComfyUI inpaint / 本机编辑工作流 |
| 原生文字 | 多语言画面内文字，标题和正文按生产版式渲染 | 分镜需要字幕、招牌、功法文字时写“画面内文字”层 |
| 尺寸 | 宽高比约 1:16 到 16:1，常用 1K/2K/3K | 本机按 9:16 / 16:9 / 1:1 适配 |

提示词长度建议：官方页面约 5000 字符，API 建议控制在 3000 字符内、600 英文词以内。更长时细节会丢失，所以本 skill 要求把长句拆成层，而不是堆形容词。

## 分层公式

本机每个 `image_prompt` 都按以下顺序组织：

```text
[格式/用途] + [主体/人物] + [构图/空间] + [光影] + [画面内文字] + [风格/质感] + [锁定项]
```

每一层都必须是可执行指令，而不是装饰。缺少任何一层，模型就会自己决定该层，容易出现角色漂移或构图失控。

### 分镜图模板

```text
16:9 仙侠漫剧横版分镜关键帧，高清电影剧照，
主体：写实动漫风格的年轻剑修「李观棋」，白色束发，青灰长袍，右手握黑色长剑，
构图：低角度中景，人物位于画面左三分之一，右侧留出剑气运动轨迹，山门与远峰作背景，
光影：傍晚逆光，人物边缘有暖金色轮廓光，面部有主光，影调冷青与暖金对比，
画面内文字：无文字，不生成字幕、水印或乱码，
风格：真实逼真、轮廓分明，皮肤有自然纹理，材质细节清晰，电影级调色，
锁定：保持参考图中李观棋的脸型、发型、服装结构、剑的形制、背景和机位不变。
```

### 参考图锁定模板

```text
保持参考图中的人物轮廓、机位、背景、光线不变，
只改变动作姿态，手臂和手指自然，衣服随动作有物理褶皱，
武器始终握在右手，不出框、不穿手，脚底不悬浮。
```

## 参考图规则

1. **按内容指代，不要按序号指代。** 写“那位白发剑修”而不是“第一张参考图”，因为参考图重排后语义仍然正确。
2. **每张参考图都要说明用途。** 例如：`参考图中的李观棋作为人物形象，参考图中的山门作为场景背景，参考图中的构图作为机位模板`。
3. **锁定项必须点名。** 说清楚哪些不能变：脸型、发型、服装结构、武器形制、背景、机位、光线。否则模型会把没提到的部分自由发挥。
4. **身份类参考用干净素材。** 角色正面、3/4 侧面、招牌动作优先用清晰、无遮挡、无夸张滤镜的图；构图和风格参考可以更艺术化。
5. **多人镜头用融合式参考。** 每个主要角色一张 canonical ref，再加一张构图参考；prompt 中按角色顺序写清人物、位置、朝向、动作、遮挡关系。

## 本机映射

`reference_bundle.json` 的 9 个图片槽位正好对应 Seedream 的参考语义：

| 槽位 | Seedream 语义 | 在 prompt 中的写法 |
| --- | --- | --- |
| `character_front` | 身份主体 | “参考图中的 XXX 作为人物形象” |
| `character_three_quarter` | 面部结构 | “3/4 侧面轮廓和头型与参考图一致” |
| `character_side` | 侧面轮廓 | “侧面轮廓与参考图一致” |
| `character_expression` | 表情范围 | “表情范围参考图中的情绪，但嘴型服从镜头要求” |
| `character_action` | 招牌动作/武器 | “招式动作和武器状态参考图中的 XXX” |
| `scene_wide` | 场景全局 | “场景结构、建筑比例和空间关系参考图中的 XXX” |
| `scene_detail` | 材质细节 | “材质、道具、纹样细节参考图中的 XXX” |
| `style_reference` | 风格 | “画风、线条、调色参考图中的 XXX” |
| `composition_reference` | 构图 | “人物站位、景别、机位模板参考图中的 XXX” |

Step 5 生成图片时必须传入 `--ref-bundle <project_dir>/reference_bundle.json`，不能只把参考图路径写在文字里而不传图。

## 与去 AI 味规则的合并

Seedream 分层结构只解决“画面是否受控”，不解决“是否有 AI 味”。因此每个 `image_prompt` 在锁定项后还要追加本 skill 的 De-AI anchor：

```text
自然姿势，正确肢体比例，自然手部，闭合嘴型（非说话镜头），
真实皮肤纹理，无塑料感，无乱码文字，无多余手指，光影方向一致。
```

## 使用时机

- Step 2：剧本按“能拍”写，每个场景的 `shot_plan` 就要给出格式、景别、机位、动作、音效，供 Step 3 直接转成分层 prompt。
- Step 3：每个镜头的 `image_prompt` 必须按七层公式重写，不能把一句话摘要直接当 prompt。
- Step 4：`prompt_fragment` 和 `style-lock.json` 保存的是可复用层，后续镜头只替换“主体动作”和“构图”层。
- Step 5：用分层 `image_prompt` 生图；参考图缺失时不能编造角色，先补 canonical refs。
