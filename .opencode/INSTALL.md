# AI Developer skills - OpenCode

1. Clone this repository:

```bash
git clone https://github.com/chichengyu/ai-developer.git
```

2. Copy every folder under `skills/skills/` into OpenCode's skills directory, defaulting to `~/.config/opencode/skills/`.
3. Restart OpenCode.

If OpenCode is already running, you can paste this prompt instead:

```text
Fetch and follow instructions from https://raw.githubusercontent.com/chichengyu/ai-developer/main/.opencode/INSTALL.md
```
